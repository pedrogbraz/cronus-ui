# __APP_NAME__

Gontify — an AI SaaS marketing site built with [Next.js](https://nextjs.org)
and [Cronus UI](https://aicronus.com). Kinetic testimonials, flowing logos,
column-line hero, and the full product landing.

## Getting started

```sh
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## What's inside
