# __APP_NAME__

A personal portfolio for Pedro Gontijo — work, projects, community, and contact —
built with [Next.js](https://nextjs.org) and [Cronus UI](https://aicronus.com).
Pixel theme transition, 8-bit sounds, and a single config file.

## Getting started

```sh
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## Config

Edit `data/resume.tsx` — name, avatar, work, projects, and socials.

Press `d` to toggle theme (pixel wave). Sound toggle lives in the navbar.

## Add more components

```sh
npx cronus-ui add dialog tabs
```
