## Limites desta evidência

- **A aceitação existe só neste registro.** Não há assinatura, issue ou PR
  aprovado no repositório que a comprove de forma independente.
- A ADR não foi revisada por terceiro. `task review` registra a minha
  avaliação do diff de uma linha, não uma segunda opinião sobre a decisão.
- Aceitar a ADR não valida o raciocínio sobre uso nominativo de marca, que a
  própria ADR declara não ser opinião jurídica.
